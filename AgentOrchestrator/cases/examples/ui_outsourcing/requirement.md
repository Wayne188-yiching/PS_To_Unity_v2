# 範例｜活動獎勵頁 UI 美術需求

製作範例遊戲的活動獎勵頁，包含主視窗、三個任務項目、領取按鈕與已領取狀態。

- 基準畫面為 1920x1080，並需確認 2560x1080 與 2760x1080。
- 主視窗使用既有共用關閉按鈕與玩家資產欄，不可修改來源 Prefab。
- 任務項目需要未完成、可領取、已領取三種狀態。
- 可領取按鈕需要簡單掃光；已領取狀態不可繼續吸引視覺焦點。
- 背景與主要內容分開，重複任務項目使用一致結構。
- 交付 PSD、原始尺寸 PNG、檢整尺寸 PNG、各狀態示意圖及 Unity Prefab。

目前尚未確認主題英文名稱、交件日期與按鈕共用 Prefab 的確切型號。
