圖層名稱

在 PS 的圖層名稱加標記，藉此在 Unity 新增對應的功能。

[SCROLL_V] ranking_list

中括號內是給工具讀的標記，其餘部分維持原本的圖層名稱。

[SCROLL_V][SCROLL_H]

自動組出 ScrollView › Viewport › Content 三層，掛上 ScrollRect 與 RectMask2D。

[GRID][V][H]

生成對應的 Layout Group；可與捲動組合，排版元件會掛在 Content 上。

[MASK]

以該圖層的形狀裁切整個群組。只有非矩形才需要；純矩形會自動改用更省的 RectMask2D。

[SLICED=32][SLICED=左,上,右,下]

寫入 Sprite Border，並把 Image 設為 九宮格 Sliced，按鈕與底框可以自由拉伸。

[MERGE]

把整個群組的可見結果烘成一張 PNG、只建一個節點。裡面還要換字或動畫時不要用。

[SCROLLBAR_V][TRACK][HANDLE]

自動接上可拖動的捲軸，並保留匯出時的 Content 初始位置。

[SOFTMASK_BOTTOM=64]

用兩層原生 RectMask2D 柔化底邊 64 像素，不必額外安裝 runtime 套件。

[PNG][CG]

指定文字圖層改輸出成圖片，或替群組加上 CanvasGroup 以便整組淡入淡出。

Unity 的階層就是 PSD 的群組結構，一層對一層。工具只會多插入 ScrollView 底下的 Viewport 與 Content 兩層，這兩層不要在 Photoshop 建；捲動內容直接放在標了 [SCROLL_V] 的群組裡即可。

其他圖層維持有意義的英文命名即可。中文命名的 PSD 請先跑 PhotoshopLayerAutoNamer.jsx，它以納入版控的 naming_glossary.tsv 做最長匹配翻譯；推不出來的圖層維持原名，並把未知詞寫進待辦表，補完再跑一次即可。

從 PSD 到 Prefab，
四個動作。

平常情況不必理解內部演算法，只要照順序完成命名、匯出、驗證與生成。

1

整理圖層

保持有意義的英文名稱；需要特殊行為時，加上 Scroll、Grid、Mask 等標記。

需要時：先跑自動命名工具
2

在 PS 匯出

執行 PhotoshopUiPackageExporter，選擇輸出位置後按 Export。

得到：PNG + Layout JSON
3

在 Unity 驗證

開啟 Importer_v2，選擇 Package、設定專案資料夾與 TMP Font Asset。

先按：Validate
4

生成 Prefab

按 Generate Prefab；完成後即可換字、換圖、做動畫與串接程式。

完成：可編輯 Unity UI

改稿之後，只是再跑一次。

Photoshop 重新 Export，Unity 重新 Generate。命名與標記留在 PSD 裡，捲動、排版、九宮格與遮罩會照原樣重建，不必再設定一次。

6 份樣本

Phase 4.5 以 6 個 ScrollRect PSD 樣本，在 Photoshop 2026 + Unity 2022.3.62f1 實機驗收通過。

生成之後，
還能一直換。

字型、皮膚與圖集各有專用工具，替換時不會動到已經排好的版面。

只換字型Font Replacer
分析 Prefab 目前用到的 TMP 字型與材質，一鍵替換。只寫 font 與 fontSharedMaterial 兩個欄位；排版、字級、顏色與 Sprite 全部不動，描邊材質會自動克隆到新字型。
整套換皮SkinTheme
用一組對應表批次換掉整套 Sprite，做節慶版或不同陣營配色。Prefab 上已經掛好的 Script 與 Button 都會保留。
圖集自動維護Sprite Atlas
生成時依 Base／CHS／CHT／EN 各建一顆語系圖集，每顆只打包自己的語系資料夾；空語系不建圖集，上限依最大來源圖自動選 2048／4096／8192。
圖層自動命名PhotoshopLayerAutoNamer
以版控中的中英詞庫翻譯圖層名，同族圖層自動編號。翻不出來的維持原名並列進待辦，不會擅自猜一個英文名字。

不確定的時候，
工具不硬做。

無法可靠重建時，工具會警告或降級，並在 Layout JSON 留下代碼，不讓錯誤在無聲中進入 Prefab。

先 Validate，再 Generate

在建立 Prefab 前檢查路徑、字型與 Package 結構，問題在生成之前就攔下來。

排版對不上就保留原座標

交叉軸有偏移時，寧可維持 Photoshop 的絕對位置，也不強制重排把文字擠進遮罩裡；v2.13.3 起連 0.5 px 偏移都會保護性降級。

LAYOUT_CROSS_AXIS_DEGRADED

配對不唯一時不猜

外置捲軸只有在整個 Prefab 剛好有一個相容且未接線的 ScrollRect 時才自動配對；有多種可能就停手並回報。

SCROLLBAR_ORPHAN_UNRESOLVED

下一步，
也許不用再開工具。

現在的流程已經夠短，但還是要有人在 Photoshop 按 Export，再到 Unity 選 Package、Validate、Generate。我們正在評估把整套包成一個 skill 搭配 agent：丟一個 PSD 檔或檔案路徑，其餘自動完成。

設想 把 Rank.psd 轉成 Unity Prefab，放進 Rank 的專案資料夾。

這是設想中的用法，目前還沒有這個功能。

要先回答的問題

  • 兩端都是 GUI 程式。匯出腳本跑在 Photoshop 裡，生成工具跑在 Unity Editor 裡；要全自動，得先決定是讓兩邊常駐，還是仍由人開好再交給 agent。
  • 命名標記需要判斷。哪一組要捲動、哪張圖要九宮格、哪一組該烘成一張，目前由設計師決定；交給 agent 之前，要先確認猜錯的代價由誰承擔。
  • 降級訊息需要有人讀。工具遇到不確定會保留原座標並回報代碼，這些訊息是要人看懂並決定怎麼處理的，不該被自動流程默默略過。
  • 中文圖層仍需人工補詞。詞庫推不出來的圖層會維持原名並列進待辦，那份對照表目前只能由人補完。
  • 責任邊界還沒畫。全自動之後，錯誤的版面在哪一步被攔下、由誰驗收，還沒有答案。

結論還沒有。放進報告是因為它會決定這個工具接下來往哪裡走，想先聽聽大家的想法。
