# 截圖放這裡

`PS_To_Unity_Showcase_zh.html` 會依檔名自動顯示下列截圖；沒放的位置會顯示「待放截圖」框。

| 檔名 | 放什麼 |
|------|--------|
| `flow-1-layers.png` | 工作流 1：PS 圖層面板（命名＋標記） |
| `flow-2-export-1.png` / `-2` / `-3` | 工作流 2：PS 選單 → 工具箱 → 匯出視窗（左右切換） |
| `flow-3-setup-1.png` / `-2` / `-3` | 工作流 3：Unity 選單 → 建立專案資料夾 → 檢查 Layout ＋ Generate（左右切換） |
| `flow-4-result-1.png` / `-2` | 工作流 4：Sprite Atlas → 生成的 Prefab（左右切換） |
| `case-1-psd.png` / `case-1-unity.png` | 案例 01：PSD 原稿 / Unity 結果 |
| `case-2-psd.png` / `case-2-unity.png` | 案例 02 |
| `case-3-psd.png` / `case-3-unity.png` | 案例 03 |

一格要放多張圖：在同一個 `<figure class="shot">` 裡依序多放幾個 `<img>`，頁面會自動出現左右切換（也可用鍵盤 ← →、手機滑動）；`alt` 文字會顯示在圖下方當說明。

案例標題與說明直接改 HTML 裡的 `<article class="case">`；要加案例就複製一整段。
