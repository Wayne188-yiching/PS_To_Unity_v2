2. Presentation information architecture

  1. Previous State：用一條 20 秒內可讀完的固定 pipeline recap 建立共同上下文。
  2. Limitation：原 pipeline 保留不動；四個語意歧義逐一附著到節點，最後停在「工具不應猜設計意圖」。
  3. Agent Layer：架構向上長出 reasoning layer，底層 deterministic core 不位移、不消失。
  4. Current PSD Agent：全報告主段，以一個 pinned timeline 走完 inspect → evidence → plan → human gate → apply → re-inspect/export。
  5. Real Case：使用 repo 追蹤的 scroll_v_basic.psd 作「安全 demo」；只展示已知結構與 acceptance intent，不假造尚未產生的 Agent result。
  6. Current Progress：以單一路線圖呈現 completed / current / partial / planned，並標示 evidence 層級。
  7. Multi-Agent Direction：最後才展開 Director、PSD Agent、Unity Agent、Pipeline Validator 與兩側 deterministic core 的責任邊界。

5. Sensitive-information gate

  • 不顯示本機絕對路徑、使用者名稱、API key、本機設定、內部 production PSD 名稱或公司資產。
  • 不讀取或嵌入 PSD/image bytes；示意圖只使用 repo 文件已公開的結構文字。
  • 不把 QC_Agent、UI 外包製作人或 vendor workflow 畫進 runtime；結尾只保留「兩條獨立 Agent 系統」一句。
  • branch / worktree 的未提交狀態只用「acceptance hardening in progress」描述，不顯示機器路徑。
